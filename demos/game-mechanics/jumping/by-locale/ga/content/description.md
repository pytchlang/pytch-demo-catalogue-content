# Gluaiseacht ar chlé agus ar dheis

Ní hé an chaoi a mbogann an Sprid príomhphointe an taispeántais seo,
ach b’fhéidir go mbeadh sé úsáideach féachaint ar an gcaoi a
n-athraímid an chulaith chun go mbeadh an carachtar ag féachaint sa
treo ina bhfuil sé ag bogadh. Ní sheiceálann an cód cá bhfuil an
carachtar ar an scáileán, mar sin is féidir leat é a bhogadh den
scáileán.


# Ag Léim

Léimeann an carachtar nuair a bhrúnn tú an eochair "space", mar sin tá
an cód sa script _nuair a bhrúitear eochair space_. Is í an
phríomhloighic a bhaineann leis an léim ná an chuid ina n-úsáidtear an
athróg `y_velocity`.  Bogaimid an carachtar suas go tapa go leor ag an
tús, ag athrú a chomhordanáid _y_ faoi 8.  Ansin laghdaímid an
treoluas go nialas, agus leanaimid á laghdú go -8, chun an carachtar a
bhogadh ar ais síos go talamh.  Is é nialas suim na n-athruithe seo go
léir ar _y_ rud a fhágann an carachtar ag an airde chéanna go díreach
is a bhí sé ag an tús. Déanann an próiseas iomlán seo aithris ar an
gcaoi a n-oibríonn an domhantarraingt.


# Léimeanna dúbailte a sheachaint

Ba mhaith linn a chinntiú nach dtosaíonn an carachtar léim nua agus é
fós i lár léime roimhe sin. Úsáideann an cód athróg Boole darb ainm
`jumping` chun súil a choinneáil air seo. Ar dtús (_nuair a
chliceáiltear ar an mbratach ghlas_), _níl_ an carachtar ag léim, mar
sin tá luach `False` ag `jumping` ISa script _nuair a bhrúitear
eochair space_, seiceálaimid ar dtús an bhfuil an carachtar i lár
léime, agus má tá, cuireann muid stop leis an script sin. Ansin
socraímid `jumping` go `True` fad atá an ghluaiseacht suas agus síos
ar siúl, agus athraímid ar ais go `False` é nuair a bhíonn an
ghluaiseacht críochnaithe.
